# Recorded voices (optional)

If an mp3 exists at `assets/voices/<speaker>/<line-id>.mp3`, the game plays it instead of the browser's text-to-speech voice. Missing files fall back to TTS automatically.

Record only voices of people who have agreed to it (for example your own family, with their consent). Do not use clips that imitate or clone anyone else's voice.

Tips: mono, 44.1 kHz, about -16 LUFS, trim silence at both ends, one line per file. File names are the line ids below, exactly.

Speakers (folders): `ammamma`, `friend1`, `friend2`, `villager_m`, `villager_f`.

## How the game finds your files

Drop the mp3s into the speaker folders (create them: `assets/voices/ammamma/`, `assets/voices/friend1/`, ...). On a
local dev server that lists folders (like `python3 -m http.server`) nothing else is needed. On a host that does not
list folders, also add `assets/voices/manifest.json` naming the recorded lines, for example:

```json
{ "ammamma": ["gm_eat", "gm_bye"], "friend1": ["fr_hey"] }
```

When `manifest.json` exists it is the only list used.
