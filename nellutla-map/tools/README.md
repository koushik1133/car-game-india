# Nellutla map data

`map-data.js` is generated by `build_map.py` from:

- **Overture Maps** release 2026-10-21 (bbox 79.180–79.212 E, 17.688–17.716 N), pulled with DuckDB:
  building footprints, transport segments (OSM plus ML-detected roads) and water.
- **traced.json**: lanes and field tracks that no dataset has, hand-traced from Esri World Imagery
  (zoom 18 mosaic, tiles x 188731–188750, y 117963–117980). Coordinates are mosaic pixels.
- Land cover (3 m cells), tree positions and roof types (concrete, tile or blue sheet) are classified from that imagery.
  The imagery itself is not shipped.

World frame: 1 unit = 1 m, +x east, +z south, origin 17.70160 N, 79.19630 E (NH-365B junction).

Rebuild: `python3 tools/build_map.py <dir with buildings.csv segments.csv water.csv mosaic18.jpg traced.json> map-data.js`

Using the map in a game:
```html
<script src="nellutla-map/map-data.js"></script>
<script src="nellutla-map/nellutla-world.js"></script>
<script>
  const world = NellutlaWorld.build(scene, window.NELLUTLA_MAP);
  // each frame: world.collide(carPos, 1.6); world.surfaceAt(x, z); world.update(camera);
</script>
```
